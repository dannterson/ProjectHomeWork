# Проект банковского виджета

## Описание:

Учебная разработка виджета банковских операций.
На данном этапе реализованы функции маскировки номеров счёта и карты, сортировки по убыванию\возрастанию даты, перевода формата даты в более привычный "ДД:ММ:ГГГГ".
Разработка велась на Python 3.13
## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/dannterson/ProjectHomeWork
```

2. Установите зависимости:
```
pip install -r requirements.txt
```
Можно пропустить, на данном этапе зависимостей нет.

## Использование:

Для проверки функций необходимо раскомментировать последние строки в модулх widget и processing.
